# 昼学シフトシステム MVP

ローカルで動く初期実装です。Python標準ライブラリとSQLiteだけで動作します。

## 起動

`run.bat` をダブルクリック、またはPowerShellで次を実行します。

```powershell
.\run.bat
```

起動後、ブラウザで以下にアクセスします。

- ユーザー側: http://127.0.0.1:8000/
- 管理者側: http://127.0.0.1:8000/admin

## 初期実装に含めたもの

- ユーザー側ホーム
- シフト希望ページ
- 氏名選択、回答履歴表示、参加可否回答、確認、送信
- シフト表閲覧ページ
- 管理者ホーム
- 月管理、希望調査の日付・期限・状態編集
- シフト表の公開/非公開切り替え
- 回答確認
- シフト作成
- 名簿管理、車出し可否ラベル編集

## 固定初期設定

- 会場: 穂波、二瀬、庄内
- 各会場の人数枠: 3人
- 参加可否: 〇、△、×
- 車出し可否: 名簿側の現在属性として管理
